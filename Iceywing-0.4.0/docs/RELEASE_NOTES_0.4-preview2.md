# Iceywing 0.4-preview3

Changes from preview1:

- CLI and bootstrap output is ASCII-only.
- Replaced the snowflake prefix with `*`.
- Standardized statuses:
  - `[OK]`
  - `[WARN]`
  - `[FAIL]`
  - `[--]` for optional/unavailable
  - `[....]` for work in progress
- Standardized flow arrows to `->`.
- Windows bootstrap no longer depends on Unicode terminal rendering.
- Version bumped to `0.4.0a3`.

No Pop Flow or Environment behavior was intentionally removed.
