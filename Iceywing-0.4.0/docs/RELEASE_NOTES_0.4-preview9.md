# Iceywing 0.4-preview9

Preview9 simplifies installation and keeps Iceywing a standard Python tool.

- standard pip/wheel in-place installation
- administrator-assisted Windows upgrade for stale console launchers
- `iceywing` and `iw` console scripts
- `python -m iceywing` fallback entry point
- importable `iceywing.Project` API
- no side-by-side custom venv/launcher version tree
- compact setup output; detailed pip output only on failure
- one post-change verification by default in Pop Flow
